# Optional keyboard controls

The default networking-only profile retains the shipped controls and adds no keyboard aliases. The optional keyboard compatibility profile adds these aliases while retaining original controller input. The game may still display controller prompts. These mappings require the corresponding generated client patch; checking out the repository does not install them.

| Key | Original prompt / action |
|---|---|
| W A S D | Left stick / movement |
| I J K L | Right stick / camera |
| Arrow keys | Menu navigation |
| Enter | UI Submit |
| E | Cross / confirm or interact |
| Escape | Circle / back or cancel |
| Tab | Square |
| F | Triangle |
| Q / R | L1 / R1 |
| F8 | L3 / left stick click |
| C | R3 / right stick click |
| P | Share |
| M | Options / menu |
| 1 / 2 | Furniture height controls |

The action depends on the current screen. Follow its controller prompts when switching tabs or opening submenus. Optional mouse look is a separately staged experiment; direction, sensitivity, focus and cursor release still need native acceptance. Test-only cursor-lock changes are separate from the production patch profile.

Keep Steam running. Steam's Play button uses the installed executable; it reaches the preservation backend only if that installation has actually been patched. A separate patched copy must be launched from its own executable. No executable is included here.
