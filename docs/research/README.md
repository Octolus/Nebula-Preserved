# Historical protocol research

These sanitized notes preserve earlier network, HTTP, TCP, avatar, social, housing, compatibility, and minigame investigations. They contain hypotheses and historical readiness statements. **The root [PROGRESS report](../PROGRESS.md) is authoritative for current completion and test results.** This archive does not establish networking parity or successful runtime acceptance.

Runtime-required manifests are kept only in [protocol](../../protocol/). This archive is documentation, not an additional runtime data source.

## Privacy and provenance

Private account/computer names, absolute local paths, private test addresses, Steam account IDs, cipher material, extracted declaration bodies and native code/listing blocks have been removed. Public shipped endpoint constants `104.196.60.146` and `104.196.161.5` are historical game constants, not project server recommendations. `203.0.113.10` is a documentation example; `127.0.0.1` and `0.0.0.0` are local/bind examples. Type names, field layouts, RVAs, protocol constants, synthetic IDs and original binary hashes may remain as research provenance.
