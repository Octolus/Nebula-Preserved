# Modern TCP application protocol contracts

Static evidence only. No client or server was launched. This is not a claim that networking is restored 1:1. `tcp-contracts.json` carries typed fields and evidence hashes; `tcp-dispatch-map.json` lists all 80 receive registrations.

All fields below follow the opcode. `guid` denotes the game's session/player identifier, not a Mirror asset Guid. Every client `TCPClient.Send` additionally appends `#StandaloneWindows` (Windows) or `#PS4` during AES encryption. Empty tokens are significant.

## Coverage boundary

80 receive contracts and 57 send contracts are reviewed across this audit and the independent BoardGames/Darts/Pool audit. The latter is imported with explicit source provenance and its source hash. The local audit contributes 46 receive contracts and 38 send contracts. Registration is proof of clientbound handling; the absence of a registration is not proof of serverbound direction. Client handlers constrain valid responses but cannot recover unshipped server policy by themselves.
