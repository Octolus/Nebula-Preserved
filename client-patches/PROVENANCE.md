# Source and license provenance

The networking-only development default uses all **70 application API request hooks** and the repaired stripped-Unity loopback consumer. Public native TLS acceptance is pending. Configured direct HTTPS is unsupported; direct six-artifact mode supports unconfigured local forwarding only. Public connections use the explicit seven-artifact remote profile, exact owned proxy, upstream CA/hostname verification and account authorization. Controls, cursor and rendering remain shipped behavior. Current source/build pins are in `network-only/network-profile-contract.json`.

The recommended preservation default is the separate **network-only** profile in
`network-only/`. It preserves shipped input assets, controls, cursor and rendering.
Its direct/TLS release plans contain six/seven artifacts and require the reviewed
explicit Rust `network-only` profile support. Runtime acceptance is pending.

The reconstruction below is retained as a **legacy optional keyboard/client-bug-fix
and testing pipeline**. Its historical profile named `default` means original
cursor only; it also contains keyboard aliases, client bug fixes and passive test
hooks. It is not the networking-only default. Never select it implicitly for
players who want shipped UI and controls. See `network-only/README.md` for the
minimal build, exact source contract and profile-switch restore requirements.

The current source-stage selection contains project-authored preservation adapters,
patch emitters and reconstruction recipes for the reviewed V9 provisional network
helper. Relative paths and exact source hashes appear in SOURCE-INVENTORY.json
and SOURCE-PROVENANCE.json. The source lock pins the 96-file foundation; the full
selection adds six entry points, documentation and lock files. Historical tests
and records retained outside that selection do not establish V9 runtime acceptance.

The complete pristine-to-target source chain is included. Default builds preserve
the original cursor behavior. Free-mouse builds require explicit selection and
use the same networking source, with only the reviewed GA macro binding changed
in the matching helper. Registry C++17 flags, preferred image base and the separate
PublicAccess source build remain preserved. See README.md and INVENTORY.md.

No original or modified complete game executable, native DLL, metadata, asset
bundle, decompiled game listing, account database, credential, fixed-slot identity
configuration or private runtime receipt belongs in this source selection.
Generated targets, scratch trees, plans and local receipts stay outside the public
repository. A published patch bundle must use source-referenced deltas and reviewed
project-owned helpers, and remain provisional until native acceptance is complete.

The game remains the property of its respective rights holders and is not licensed
by this repository. No new license grant has been assigned to the preservation
source during curation; the project owner must select the intended project license.
Do not infer that the game's license or a dependency's license applies to project
source. Dependencies and toolchains retain their upstream licenses.

The original game's service hostname and public IPs are retained only as exact
rewrite targets from the shipped protocol. They contain no operator or user host
information. Endpoint selection belongs to the Rust patcher at installation.
Receipt-managed updates can recover pristine inputs from verified local backups;
only compiled supported-original hashes authorize those inputs. Receipts and
complete backup files stay private and are not part of a source or delta bundle.
